# Выбранный поток и архив интенсива

## Реализовано в исходном коде
- Общий выбор текущего потока / архивного потока для административных разделов интенсива. Выбор сохраняется при переключении разделов.
- Задания и ответы ограничены выбранным потоком. Явный `homework_assignments.stream_id` приоритетнее текущей привязки перенесённого участника; поздний ответ остаётся у исходного задания.
- Новое ДЗ получает выбранный поток, включая персональные задания. Пользовательские web-ДЗ ограничены потоком профиля. Telegram путь не изменён.
- Команды, капитаны и интенсивный календарь используют общий выбор; истории тренировок, аскез, тотемов, Купера и журнала дополнительно ограничены периодом потока по Москве.
- Архив не показывает текущие агрегированные баллы как исторические в списке участников.
- Данные не удалялись, не переносились. SQL, Edge deployment, платежи, бот и публикация не запускались.

## Ограничения, не скрывать
- Исторический состав восстанавливается только из сохранившихся профилей и команд потока. После переносов без сохранённой истории нельзя гарантировать полноту архивного состава.
- Для записей без stream_id используется дата и доступный состав. Это не доказательство исторической принадлежности и не полноценный исторический рейтинг.
- Общие материалы сохранены без новой эвристики фильтрации: `materials.stream_id` относится к отдельной таблице `intensive_streams`, не к `streams`. Требуется подтверждённая связь идентификаторов; совпадение названия недостаточно.
- Отдельные экраны с общими уровнями/шаблонами и заглушками не превращены в потоковые данные. Полная изоляция «всех блоков» ещё требует исторической модели и проверки реального кабинета.
- Реальные авторизованные end-to-end проверки недоступны для external unmanaged Supabase.

## Откат / включение
Изменения frontend обратимы через обратный patch соответствующих коммитов. Миграций UP/DOWN нет. До публикации проверить реальные задания/ответы и переходы между потоками под основательским аккаунтом; дальнейшую историческую модель согласовать отдельно, без изменения production в этом этапе.
